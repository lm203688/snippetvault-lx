SnippetVault Privacy Policy

Last updated: 2026-11-18

1. Scope

SnippetVault is a local-first VS Code extension. By design:

  • No analytics, telemetry, or crash reporting is collected.
  • No data is uploaded to any server during normal use.
  • All snippets you create, edit, or manage remain on your local machine.

2. What We Access

When installed, SnippetVault requests the following VS Code capabilities:

  • Workspace files — to read and write .code-snippets JSON files in your project and global snippets folders.
  • Active editor — to insert snippet text at your cursor position.

We do not access network resources except when you explicitly choose to activate Pro (see §4).

3. License Verification (Pro Only)

If you activate a Pro license key, the extension makes a single HTTPS POST to our verification endpoint (snapmark-license.workers.dev/verify). The payload contains only the license key string; no snippet content, file paths, or identifying information is transmitted. The server returns a simple {"valid": true/false} response.

4. Data Retention

License keys are verified against our Cloudflare Worker backend (snapmark-license.workers.dev). Upon successful verification, the active status is cached in your VS Code globalState. Expired or revoked license keys remain in local storage but will no longer pass server-side verification. License keys stored on the server side are managed by Cloudflare KV according to their own data retention policies.

5. Third Parties

We do not share, sell, or expose your snippet content or personal data to any third party. Your license key is sent solely to our Cloudflare Worker for verification. Payment processing is handled by Paddle under their own privacy policy. No analytics, advertising, or telemetry providers are involved.

6. Children's Privacy

SnippetVault does not knowingly collect personal information from children. If you are under 16, please use the extension only with parental guidance.

7. Your Rights

Since we do not process personal data beyond what is strictly necessary for license verification, there is no data subject access request mechanism. You may uninstall the extension at any time to remove all locally stored state.

8. Contact

For privacy-related questions, email support@lxstudio.app.
